# Pokemon Demonstrator

## Data Source

The input data (`pokedex.json`, `pokedex_small.json`, `pikachu_data.json`, `items.json`, `items_small.json`, `moves.json`, `moves_small.json`, `types.json`) is sourced from the public GitHub repository [Purukitto/pokemon-data.json](https://github.com/Purukitto/pokemon-data.json).

This data is used solely for demonstration purposes to illustrate the WBML mapping pipeline described in this project.
